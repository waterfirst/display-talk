# Display Industry Talk — HTML Slide Deck

대학 특강용 디스플레이 산업 소개 발표 자료.

## Features
- 붓글씨(캘리그라피) 스타일 커버 — "픽셀 너머의 세계"
- 5-slide HTML presentation (no framework needed)
- 반응형 (모바일/태블릿/데스크탑)
- 키보드(←→) + 터치 스와이프 내비게이션

## Slides
1. **Cover** — 캘리그라피 타이틀 + 프로필
2. **시장과 기술 흐름** — OLED/LCD 시장, 기술 트렌드
3. **SID 2026 트렌드** — Dual View, FMM-Free, Glass Interposer, AI
4. **직무 소개** — 공정개발, 품질, 설계, 연구, AI/데이터
5. **Q&A**

## Usage
```
open index.html
```
Or deploy via GitHub Pages.
